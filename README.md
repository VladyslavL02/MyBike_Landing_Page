# My Bike Landing Page

A modern, responsive landing page created to showcase bicycle models and features. This project focuses on precise markup implementation, smooth user interactions, hover effects, and modern CSS/SCSS styling techniques.

## Live Preview

[My Bike Demo](https://VladyslavL02.github.io/MyBike_Landing_Page/)

## Technologies Used

**Core**

- HTML5 – Semantic markup and accessible document structure
- SCSS / CSS3 – Modular BEM architecture, responsive layout, and CSS transitions
- Parcel – Asset bundling, SCSS compilation, and local development server

**Code Quality & Formatting**

- ESLint – Code quality and linting
- Stylelint – SCSS syntax and style rules validation
- Prettier – Automated code formatting

**Deployment & Hosting**

- GitHub Pages – Public hosting and live preview deployment

## Getting Started

To set up the project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/VladyslavL02/MyBike_Landing_Page.git
   cd MyBike_Landing_Page
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the project locally:

   ```bash
   npm start
   ```

## Features

- **Responsive Design:** Fully optimized for all screen sizes and devices (mobile, tablet, and desktop) using SCSS media queries and custom grid mixins.
- **Pure CSS Slide-Out Menu:** Interactive mobile navigation built using the native `:target` selector, allowing seamless menu toggling without heavy JavaScript logic.
- **Bike Comparison Grid:** Product showcase featuring different model options with price tags, descriptions, and interactive hover animations on product cards.
- **Feature & Details Showcase:** Multi-column grid layout highlighting key product specs.
- **Contact & Booking Form:** Clean contact section equipped with native HTML inputs, along with direct phone, email, and interactive address links.
- **Modular SCSS Architecture:** Cleanly organized using BEM methodology, reusable typography and layout mixins, custom CSS transitions, and standardized variables.
